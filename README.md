# Складка

Конструктор упаковки в браузере: развёртки коробок по размерам, 3D-сборка, логотипы и надписи снаружи и внутри, экспорт для типографии.

## Запуск

Откройте `index.html` в браузере (Chrome, Safari, Firefox). Сборка не нужна. Интернет нужен только для загрузки Three.js, jsPDF и шрифтов.

## Что умеет

- 10 шаблонов: клапаны с разных/одной стороны, склейка, клапан + склеенное дно, европодвес, окошко, футляр, лоток, крышка-дно, самосборная для доставки
- Своя конструкция: тип закрытия каждого конца, язычок, клеевой и пылевые клапаны, выемка под палец, окно, подвес
- Логотипы и надписи на любой грани, снаружи и внутри, перетаскивание на развёртке
- Экспорт: PDF 1:1 в мм (дизайн + рез/биговка, оборот вторым листом), SVG с дизайном, SVG-шаблон, PNG-мокап
- Свои шаблоны и проекты в .json

Красная линия — рез, синий пунктир — биговка, вылеты 3 мм. Толщина картона не учитывается — перед тиражом сверьте развёртку с типографией.
